## Воспроизведение

Из корня проекта, в терминале с графическим протоколом:

```bash
env -u NO_COLOR presenterm --config-file slides/presenterm.yaml slides/talk.md
```

Для статического просмотра:

```bash
presenterm --config-file slides/presenterm.yaml slides/final.md
```

Автоматическая проверка файлов и PTY:

```bash
python3 scripts/check_slides.py
```

Пересборка исходников (нужен `rsvg-convert`, шрифты уже локальные):

```bash
python3 scripts/build_slides.py
```

Сценарии Go-демо пройдены по порядку 6 → 9 → 10 → 11 → запасной 8. Чистый запуск выполнен командой README в новом project `last-ticket-go-cleancheck` на порту 18090. Отдельная приёмка с Kafka на `last-ticket-go-acceptance` проверяет деньги, остаток, реальные PID, exit73 и совпадающие координаты повторного чтения. Матрица и команды — в [приёмке](../docs/ACCEPTANCE.md). Устный хронометраж остаётся отдельной человеческой репетицией.
